## Why

Сейчас пользователь может читать модель и менять файлы через внешнего агента/MCP, но ряд повседневных действий требует ручной работы с YAML и Git. Нужен универсальный набор средств в интерфейсе SEAF для безопасного редактирования, исследования архитектуры и работы с диаграммами с сохранением текущих проверок.

## What Changes

- Автономные черновики, мастер подключения/диагностики и редактор любых объектов: точечные и пакетные операции с предварительным diff.
- Воспроизводимые снимки, фокус на подграфе, потоки данных и зоны доверия, семантический diff, изолированный preview ветки.
- Ответы внешнего AI-агента с проверяемыми источниками и явная проверка противоречий между источниками.
- Импорт draw.io с распознаванием компонентов/связей, экспорт модели, встроенное открытие, редактирование и сохранение существующих диаграмм.
- Обязательная документация для каждой функции в **Доработки LSV**: как пользоваться, пример ShopFlow, ограничения и проверка. Переход на OpenSpec: baseline masters, delta specs, design, tasks, acceptance.
- Совместимость: существующие YAML, источники read-only и MCP proposal/validate/apply продолжают работать; схемы вводятся расширениями. Локальное сохранение не выполняет Git push.

## Capabilities

### New Capabilities

Нет новых capability paths: ниже перечислены расширения существующих основ, зафиксированных master-спецификациями.

### Modified Capabilities

- `offline-drafts`: долговечные локальные черновики, экспорт/импорт, обнаружение конфликтов при публикации.
- `connection-diagnostics`: выбор проекта, диагностика доступности, объяснимые действия восстановления.
- `object-editing`: создание/изменение/удаление объектов любых разделов, свойства и атомарные пакетные операции.
- `architecture-snapshots`: манифест содержимого и контроль воспроизводимости снимка.
- `subgraph-focus`: выбор компонента, глубины и направления, фильтрация связей.
- `dataflow-trust`: аннотации потоков/зон и проверка пересечений границ.
- `semantic-diff`: сравнение добавленных/удалённых сущностей и изменённых свойств/связей.
- `branch-preview`: изолированный просмотр Git ref без изменения текущего портала.
- `grounded-answers`: контракт источников для утверждений и обработка недостающих данных.
- `source-contradictions`: отчёт о несогласованных утверждениях с обеими сторонами источников.
- `drawio-roundtrip`: распознавание, сопоставление ID, экспорт и безопасное встроенное редактирование.

## Impact

Слой MCP/локального API, интерфейс портала, сохранение черновиков, Git/preview процессы и интеграция draw.io. Изменения архитектурных файлов по-прежнему проходят один проверяемый proposal. Документация публикуется в ShopFlow как доступный пример, однако операции принимают project ID и не зависят от ID demo.shop.*. Данные сторонних диаграмм проходят ограничения размера и безопасный разбор; внешний draw.io host конфигурируется явно. Критерии приёмки и ограничения описаны в design и acceptance, а не подразумеваются наличием интерфейса.
