# SEAF: удобство работы и конструктор схем

## Why
Пользователь ежедневно работает с сотнями систем и интеграций. Поиск ограничен разделом, длинный реестр обрезается, ошибки технические, а переходы между объектами, схемами и редактированием требуют лишних действий. Нужна сборка архитектурных схем в интерфейсе с реальным сохранением исходников.

## What Changes
1. Единый поиск и команды Ctrl+K.
2. Реестры без потери результатов: фильтры, сортировка, страницы, колонки, сохранённые представления.
3. Понятные результаты проверок с переходом к объекту и полю.
4. Паспорт объекта: свойства, связи, документы, происхождение.
5. Видимый контекст проекта и стадии diff → проверка → история → обновление портала.
6. Автоматическое сохранение незавершённых форм, восстановление, undo/redo без автоматической публикации.
7. Мастер создания системы и связанных объектов одним черновиком.
8. Избранное, недавние объекты и воспроизводимые URL.
9. Пошаговый просмотр сценариев взаимодействия.
10. Понятные формы, помощь, обязательные поля и клавиатурная доступность.
11. Конструктор сетевых, прикладных и компонентных схем с редактируемыми определениями в файлах проекта.

## Impact
Workbench frontend/backend, документация, примеры, OpenSpec и переносимая поставка. Источники пользовательских проектов не меняются при просмотре или автосохранении формы. Публикация изменений требует diff и успешной проверки. Для Git создаётся локальный коммит; push только явно. Публикация этого форка отдельно разрешена пользователем только в закрытый GitHub `flaojke/seaf-portable-workbench`.

## Non-goals
Нет публикации корпоративных данных, иных проектов, credentials, старой локальной Git-истории или машинных конфигураций. Не меняются сторонние read-only репозитории. Нет обхода проверки модели или скрытой отправки данных AI-сервисам.
