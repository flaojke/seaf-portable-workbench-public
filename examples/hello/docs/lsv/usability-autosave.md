# Автосохранение формы, отмена и повтор

## Как пользоваться

Поля и расширенный JSON автоматически сохраняют текст в браузере. Состояние показано под формой. Кнопки **↶ Отменить** и **↷ Повторить** меняют только локальный ввод. Для клавиатуры вне текстового поля доступны Ctrl+Z / Ctrl+Shift+Z; внутри поля работают привычные средства браузера.

Можно перейти к другому объекту, вернуться и восстановить незавершённый ввод. Данные проектов разделены. Незавершённый JSON тоже сохраняется как текст, хотя подготовить предложение из него нельзя.

## Пример

Откройте Delivery Service, измените владельца с `Logistics` на `Platform`, отмените и повторите изменение. Перейдите к заказам и вернитесь: ввод останется. До проверки и явного сохранения YAML не меняется.

## Если хранилище недоступно

SEAF показывает ошибку сохранения и не выдаёт её за успех. Чтобы не потерять ввод, оставьте форму открытой и нажмите **Скачать ввод формы**. Файл содержит `editorValue`, включая незавершённый JSON; его можно восстановить вручную в расширенном редакторе. Готовый корректный черновик экспортируется отдельно через **Экспорт JSON** и импортируется в **Черновиках**.

## Ограничения

Локальный ввод связан с профилем браузера, адресом/портом сервиса и проектом. Очистка данных сайта или перенос на другой компьютер его не переносит. Переносимый запуск повторно использует прежние свободные порты; если они заняты, новый порт создаёт другой браузерный origin, а старый ввод остаётся доступен по прежнему адресу. История отмены ограничена. При изменении модели после сохранения текста появляется предупреждение; проверьте новый diff. Автосохранение не выполняет Git-коммит, push или публикацию.
