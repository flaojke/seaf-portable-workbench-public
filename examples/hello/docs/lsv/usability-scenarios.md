# Пошаговое прохождение сценариев

## Как пользоваться

1. Откройте **Сценарии** и выберите распознанный сценарий из источников проекта.
2. Кнопки **Предыдущий / Следующий** показывают сообщение и выделяют его участников.
3. В карточке шага смотрите данные, протокол и условия/ошибки, если они заданы источником.
4. Нажмите участника, чтобы открыть его паспорт, или имя исходного файла для проверки.

Можно выбрать **Собрать маршрут из связей модели**: добавляйте существующие взаимодействия в нужном порядке. Этот маршрут хранится локально и не изменяет архитектурные файлы.

## Пример ShopFlow

Выберите сценарий оформления заказа. Последовательно рассмотрите взаимодействия заказов, оплаты и доставки. Для собственного маршрута выберите связь заказов с Delivery Service и добавьте её как шаг.

## Ограничения

Это просмотр описания архитектуры, а не трассировка работающих микросервисов. Ветви Mermaid (`alt`, `else`, `opt`) показываются с подписями из источника; просмотр всех сообщений по порядку не означает, что все ветви исполняются одновременно. Поддерживаются распознаваемые sequence-диаграммы и явные шаги; произвольный текст не интерпретируется догадкой. Неоднозначный участник остаётся неразрешённым, а не превращается в выдуманный компонент.
