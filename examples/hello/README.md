# Hello: системы и справочники

Три компонента: Web App → API Service → Database. [Открыть карту](/entities/contexts/plantuml?dh-context-id=demo.hello).

Откройте «Редактор», выберите demo.hello.api. Поле «Владелец» берёт значения из catalogs.teams; «Статус» — из schema.enum. Измените значение, покажите diff, проверьте и сохраните. В таблице потоков можно изменить HTTPS/SQL взаимодействие.

Проект хранится как обычная папка, локальная история находится в data/state. Для изменения Git-примера подключите отдельный клон. Внешние сервисы и интернет этому примеру не нужны.
