# Автономные черновики

> Переносимый профиль: Базой черновика может быть Git-коммит или локальная ревизия (64 hex-символа). Fingerprint импортов проверяется в обоих режимах. Применение к обычной папке сохраняет локальную историю без .git. См. [инструкцию Windows](/entities/docs/blank?dh-doc-id=local.lsv.portable).

Feature: **27**. Capability: `offline-drafts`.

Откройте [рабочее пространство SEAF](/entities/docs/blank?dh-doc-id=local.lsv.workbench) или [страницу рабочего пространства](/entities/docs/blank?dh-doc-id=local.lsv.workbench). Выберите нужный проект; ниже пример для ShopFlow.

Черновик позволяет подготовить изменения объектов без немедленной записи в Git. В браузере сохраняются загруженная модель и операции; серверные черновики доступны после подключения.

## Как пользоваться

1. Откройте рабочее пространство при работающем сервисе и выберите **ShopFlow**. Первый успешный вход нужен для загрузки модели и кеширования оболочки.
2. В **Объекты** найдите нужный ID и подготовьте JSON. Нажмите **Сохранить локально**. Корректный JSON также автоматически сохраняется после паузы ввода.
3. Откройте **Черновики**. Локальные записи помечены **В браузере**, серверные — **На сервере**. Нажмите **Открыть**, чтобы выбрать черновик.
4. Кнопка **Экспорт JSON** в редакторе, **Экспорт** в списке либо **Экспорт черновика** скачивает JSON. **Импорт JSON** восстанавливает его в локальном хранилище.
5. После восстановления сервиса нажмите **Обновить**. Откройте черновик и выберите **Проверить в SEAF**.
6. Изучите diff. Только после успешной проверки нажмите **Сохранить в Git и обновить SEAF**.

## Пример ShopFlow

В разделе `components` выберите `demo.shop.delivery`, операцию **Изменить указанные свойства**, введите:

```json
{
  "description": "Доставка подтверждённых заказов; заявки ShipmentCreated и повторные попытки."
}
```

Нажмите **Сохранить локально** и экспортируйте JSON. До применения поле в рабочей модели не меняется. После повторного подключения проверьте, что diff относится только к выбранному объекту и его description.

## Ограничения

Автономно доступны ранее загруженная модель и локальные операции. Runtime-проверка, diff на сервере, Git, снимки, граф и preview требуют сервиса. Для надёжного автономного открытия используйте прямую вкладку рабочего пространства; портал сам по себе может быть недоступен.

Хранилище относится к текущему origin и профилю браузера. Очистка данных сайта удаляет локальные записи; JSON-экспорт нужен для переноса. Автосохранение обновляет запись для текущего раздела и набора выбранных ID; кнопка **Сохранить локально** создаёт отдельный черновик. Текст незавершённого JSON восстанавливается отдельно от готовых операций.

Последний выбранный проект сохраняется вместе с браузерными данными. После повторного открытия проверьте его имя в верхнем списке: при недоступном хранилище восстановление между сессиями не гарантируется.

## Если браузер не может сохранить черновик

При запрете IndexedDB/localStorage или исчерпании квоты интерфейс показывает ошибку сохранения. Текущий JSON остаётся в редакторе; нажмите **Экспорт JSON** и сохраните файл на компьютере. Успешный экспорт означает скачивание файла, а не запись в браузер или Git.

Для проверки переноса откройте новую сессию рабочего пространства, выберите тот же проект и импортируйте файл. В нём сохраняются project, baseHead, baseFingerprint и операции. Перед публикацией сервис повторно сверяет исходную версию; устаревший черновик остаётся доступным для разбора.

Изменение исходного Git-коммита или fingerprint workspace блокирует публикацию старого черновика. Автоматического слияния нет: сравните данные и подготовьте изменение заново.

Экспорт использует format `seaf-draft-v1`. При импорте проверяются project, поддерживаемый format, корректная исходная версия, структура операций и путей файлов; сначала выберите соответствующий проект. Неизвестная версия, несовпадающий project и некорректный JSON черновика отклоняются до приёма операций. Полноценная миграция версий и межпроектное сопоставление не выполняются; модель дополнительно проверяется сервером перед публикацией.

## Где хранятся данные

Локально: IndexedDB `seaf-workbench-v1`, с fallback на localStorage. На сервере: `seaf-mcp/state/workbench/drafts`. Файл JSON не является Git commit.
