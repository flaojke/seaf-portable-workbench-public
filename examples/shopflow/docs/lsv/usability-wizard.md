# Мастер создания системы

## Как пользоваться

Откройте **Моя работа → Создать систему** или **Редактор → Мастер создания**.

1. **Система:** выберите тип объектов, уникальный ID и название.
2. **Ответственность:** задайте владельца и назначение.
3. **Интеграции:** для `components` добавьте получателей, назначение взаимодействий и протоколы.
4. **Схема и проверка:** добавьте систему в существующий контекст или создайте новый. Нажмите **Подготовить diff системы**.
5. В черновике изучите связанные операции, проверьте их и явно сохраните.

## Пример ShopFlow

Создайте `demo.shop.notifications`, название `Notification Service`, владелец `Commerce`. Добавьте взаимодействие с `demo.shop.orders` «Получить сведения о заказе», протокол `HTTP`. Выберите подходящий контекст. Одно предложение создаст компонент с `links` и обновит контекст; частичная запись этих операций не выполняется.

## Ограничения

Для нестандартного раздела систем мастер создаёт общие свойства, но не выдумывает структуру интеграций чужой метамодели. Интеграции и контексты мастера используют стандартные `components`/`contexts`. Если модель изменилась после начала мастера, подготовка блокируется: ввод остаётся, но нужно актуализировать основание. Read-only проекты не допускают создание.
