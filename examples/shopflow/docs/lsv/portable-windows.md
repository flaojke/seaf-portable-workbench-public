# SEAF-Portable для Windows

Комплект рассчитан на Windows 10/11 x64. Node.js, Git, Java, PlantUML и клиент draw.io включены в поставку. Для работы с локальными проектами интернет, Docker, установка Node.js и права администратора не требуются.

## Запуск и перенос

1. Полностью распакуйте ZIP в доступную для записи папку. Не запускайте файлы непосредственно из ZIP.
2. Запустите `Start.cmd`. Откроется браузер с SEAF; адреса локальных сервисов записываются в `data/run.json`.
3. В меню **Проекты** выберите ShopFlow или подключите свою папку. **Редактор** позволяет подготовить и проверить изменения.
4. Перед переносом запустите `Stop.cmd` и дождитесь остановки. Копируйте папку комплекта вместе с `data`, если нужна история и настройки.
5. На новом компьютере снова запустите `Start.cmd`. Внешние проекты остаются по своим исходным путям: отсутствующую папку нужно переподключить или перенести отдельно.

Внутренние проекты используют относительные пути. Не переносите работающие процессы и не редактируйте файлы runtime вручную. Для обновления используйте новый комплект; сначала сохраните копию data и собственных проектов.

Выбранный в «Проектах» активный проект сохраняется в `data/projects.json` и восстанавливается после перезапуска. `activeProject` в `data/settings.json` используется только для первоначального выбора примера.

Проверка manifest обнаруживает изменённые, отсутствующие и лишние файлы в неизменяемых `app/runtime`. Пользовательские файлы располагаются в `data`. ZIP публикуется только после полной записи: незавершённый `.partial` не считается готовой поставкой.

## Пример ShopFlow

Откройте **Проекты → ShopFlow → Открыть**, затем **Редактор**. Выберите `demo.shop.delivery`, измените название или владельца, нажмите **Показать изменения → Проверить в SEAF → Сохранить и обновить SEAF**. Локальная папка получает ревизию; Git-проект получает локальный коммит.

Схемы и draw.io обслуживаются локально. Проверка черновика и preview используют отдельную копию проекта. `Stop.cmd` останавливает процессы своего комплекта, а не все процессы Node.js или Java на компьютере.

## Исходники и будущий Git

В исходном репозитории хранятся `vendor/seaf-archtool-core`, `seaf-mcp`, `portable`, `examples`, OpenSpec и lockfiles. Сборщик создаёт отдельный ZIP с manifest и контрольными суммами. `dist`, runtime-бинарники, node_modules, data, локальные настройки, логи и токены не коммитятся. Лицензии исходного ядра и включённых компонентов сохраняются в комплекте.

## Ограничения

- Профиль поставки — Windows 10/11 x64; ARM64 и старые Windows не проверены.
- Git-серверы и внешние AI требуют сети и собственной авторизации. Комплект не содержит пользовательских токенов или SSH-ключей.
- Для SSH используются ключи пользователя; URL с встроенным паролем не принимается. Не передавайте папку data посторонним без проверки её содержимого.
- Автономный режим запрещает сетевые импорты и сетевые include PlantUML. Внешние зависимости следует сохранить локально и подключить относительными импортами.
- Снимок фиксирует runtime identity; для его воспроизведения нужен комплект с совпадающими runtime-файлами.

Предыдущие инструкции по Docker относятся к сохранённому альтернативному профилю запуска.

Локальный draw.io обслуживает клиентское редактирование и XML; облачные функции, серверный PDF-export и MathJax не входят в offline-профиль.
