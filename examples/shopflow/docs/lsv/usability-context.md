# Контекст проекта и сохранения

## Автономный запуск

Версия ядра в шапке берётся из локального пакета. В переносимом комплекте необязательная аналитика отключена, а показ версии не обращается к внешнему сервису обновлений. Подключение к Git-серверам и внешним AI выполняется при использовании соответствующих функций и требует собственной настройки.

## Как пользоваться

Строка под верхней панелью всегда показывает выбранный проект, Git или локальную папку, путь, версию и режим доступа. Для Git дополнительно отображается ветка, если она доступна.

Состояния различаются:

1. **Форма сохранена в браузере** — YAML и Git ещё не изменены.
2. **Diff подготовлен** — нужно проверить предложение.
3. **Модель проверена** — можно явно сохранить.
4. **Версия сохранена** — создан Git-коммит либо локальная ревизия.
5. **Портал обновлён** — SEAF подтвердил перезагрузку модели.

## Пример

Измените описание Delivery Service. Убедитесь, что сначала указано локальное сохранение формы. После diff и проверки сохраните изменение. Если версия записана, но портал не обновился, нажмите **Повторить обновление портала**: второй коммит не создаётся.

## Ограничения

Строка относится к проекту рабочего пространства. Портал другого проекта открывается через **Проекты → Открыть**. Отображаемая версия не заменяет содержимое diff. Локальное сохранение не является Git push, а наличие API не доказывает готовность всей метамодели или внешних сервисов.
