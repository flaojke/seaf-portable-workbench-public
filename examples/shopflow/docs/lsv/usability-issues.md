# Понятные результаты проверки

## Как пользоваться

1. Подготовьте изменение и нажмите **Проверить в SEAF**.
2. При ошибках прочитайте карточки: описание, правило, идентификатор объекта и поле, если они заданы диагностикой.
3. Нажмите **Открыть поле для исправления** или **Открыть объект**.
4. Исправьте ввод и снова нажмите **Показать изменения**, затем проверьте новый diff.

Исходная диагностика сохранена в раскрываемом блоке. Если правится объект из составного черновика операций, остальные операции остаются в обновлённом предложении.

## Пример

Правило обнаружило: «У `demo.shop.delivery` не указан владелец». Перейдите к полю **Владелец**, укажите `Logistics` и подготовьте новый diff. Старая успешная проверка не разрешает сохранить более новый ввод: при редактировании её разрешение сбрасывается.

## Ограничения

Переход доступен только при однозначном ID из результата правила или его ссылки. Неизвестное пользовательское правило остаётся видимым с подробностями; объект и способ исправления не выдумываются. Для файловых черновиков исходное предложение остаётся в списке: исправление объекта само по себе не переписывает произвольный документ или схему.
