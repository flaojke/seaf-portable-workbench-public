# Работа с ShopFlow через MCP

Внешний агент подключается к серверу seaf. Проект: shopflow.

Примеры запросов:

- Какие сервисы участвуют в оформлении заказа? Приведи файлы-источники.
- Найди зависимости Order Service.
- Добавь сервис доставки и покажи diff перед применением.

Порядок работы: прочитать модель и исходные файлы, подготовить propose_change или propose_entity, изучить diff, выполнить validate_change, затем apply_change.

Изменения проверяются отдельным экземпляром SEAF, сохраняются локальным Git-коммитом и загружаются в портал. Git push не выполняется. После изменения обновите страницу.

Новые файлы необходимо включать в imports. SmartAnts строится из YAML; Mermaid-сценарии обновляются отдельными изменениями в том же предложении.

Настройки проектов: ./seaf-mcp/projects.json. Инструкция: ./seaf-mcp/README.md.
