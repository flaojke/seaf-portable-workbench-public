# Проверки, ошибки и рабочий пример

## Перед подключением

- Найден правильный корень и YAML-манифест; все локальные imports находятся внутри validation workspace.
- ID уникальны в пределах определения, родители и получатели links описаны; циклов импортов нет.
- У компонентов есть `title` и `entity`; у контекстов — `title`, а указанные ID существуют.
- Компоненты включены хотя бы в один контекст, включая родителей, если этого требует встроенная проверка.
- Справочники, аспекты, datasets и плагины действительно подключены, а не только упомянуты.
- Пароли и токены вынесены из модели; передача репозитория и runtime не требует передачи личных credentials.

## Три слоя проверки

| Слой | Что проверяет |
|---|---|
| Разбор | YAML/JSON/XML, уникальные ключи, разрешённые пути и imports. |
| Метамодель | Схемы сущностей и встроенные правила целостности: родители, контексты, отсутствующие объекты. |
| Проект | Дополнительные validators: например owner/description микросервиса и корректность links в ShopFlow; trust/flow проверки нашей доработки. |

Успешный parse не равен корректной архитектуре. Hello проходит встроенные проверки; ShopFlow — встроенные и свои дополнительные правила. Их число зависит от подключённой метамодели, поэтому требовать одинаковое количество validators от всех проектов нельзя.

## Как проверить правку

**Редактор → Показать изменения → Проверить в SEAF → Сохранить и обновить SEAF.** Проверяется отдельная копия workspace. Изменение файлов между подготовкой и применением блокирует устаревшее предложение. После сохранения результат отдельно показывает commit/local revision и reload; ошибку reload можно повторить без повторного сохранения.

| Ошибка | Что исправить |
|---|---|
| Missing manifest/import | Путь, имя файла, выбранный общий workspace. |
| Parent component not defined | Описать `demo` и `demo.hello` перед `demo.hello.api`. |
| Component outside context | Добавить компонент/родителей в подходящий contexts.components. |
| Unknown target | Определить получателя links или исправить ID. |
| Dataset not found вместо query | Заключить JSONata в `(...)`. |
| Stale proposal / dirty Git | Перечитать модель, согласовать внешние правки, подготовить новое предложение; не затирать изменения. |

## Проверенный старт

Откройте **Проекты → Hello → Открыть**. Файлы `root.yaml`, `architecture.yaml`, `docs.yaml`, `README.md` — полный небольшой образец. В редакторе у `demo.hello.api` доступны справочник владельца и enum статуса; контекст `demo.hello` показывает Web → API → БД. Измените статус, просмотрите diff, проверьте и сохраните локальную ревизию. Для L2 скопируйте состав этого контекста в пример из раздела «Схемы и C4 L2».

Источники: `public/metamodel/dochub/rules/validators.yaml`, ShopFlow `architecture/rules.yaml`, `seaf-mcp/engine.mjs`. Эти требования подтверждены по версии исходников; внешние плагины могут добавлять свои обязательные поля и проверки.
