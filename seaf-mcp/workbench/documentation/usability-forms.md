# Понятные поля и доступное управление

## Как пользоваться

Откройте форму объекта. Общие свойства имеют понятные названия; поля схемы — описания, справочники и подсказки. Звёздочкой отмечены обязательные поля. При пустом обязательном значении форма показывает сообщение рядом с ним.

Клавиша **Tab** переводит фокус между элементами, **Enter** активирует кнопку. Фокус виден рамкой. У полей есть связанные подписи и описания для средств доступности.

Блок **Расширенные свойства: JSON и произвольные поля** можно свернуть. Неизвестные форме свойства остаются в JSON и не удаляются при изменении другого поля.

## Пример

Откройте Delivery Service. Измените **Описание** обычным полем; пользовательские вложенные свойства останутся. Если метамодель объявляет справочник владельцев или enum статусов, выберите значение из списка. Для сложной структуры раскройте JSON и затем проверьте итоговый diff.

## Ограничения

Понятная подпись не переименовывает реальный ключ в YAML. Обязательность и списки берутся из доступной схемы; неизвестная метамодель может потребовать расширенного JSON и своего пакета определений. Проверка формы дополняет, но не заменяет валидаторы SEAF. Сложные вложенные типы и неподдерживаемые конструкции JSON Schema остаются в расширенном редакторе.
