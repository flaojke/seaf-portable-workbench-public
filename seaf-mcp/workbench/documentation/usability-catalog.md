# Реестры больших моделей

## Как пользоваться

1. Откройте **Редактор** и выберите раздел модели.
2. Используйте поиск по реестру и фильтры **Владелец**, **Домен / группа**, **Статус**.
3. Выберите сортировку и направление **А—Я / Я—А**.
4. Через **Колонки** настройте отображаемые свойства. Переключайте страницы или размер страницы — 25, 50, 100, 200 объектов.
5. Нажмите **Сохранить вид**, задайте название. Позже выберите его в **Сохранённом представлении**.

**Выбрать показанные** отмечает только текущую страницу. Уже отмеченные объекты других страниц сохраняются в выборе; число видно над таблицей.

## Пример

Для модели предприятия выберите владельца `Logistics`, домен `Core`, статус `active`, добавьте колонку статуса и сохраните вид «Активные системы Logistics». Сортировка и фильтры применяются ко всему набору до разбиения на страницы.

## Ограничения

Фильтры используют доступные общие свойства объектов (`owner`, `domain`/`group`, `status`/`stage`/`lifecycle`/`live-stage`). Они не преобразуют корпоративную метамодель. Все совпадения доступны через страницы; прежнего ограничения первыми 250 объектами нет. Представления сохраняются только в текущем браузере для данного проекта.
