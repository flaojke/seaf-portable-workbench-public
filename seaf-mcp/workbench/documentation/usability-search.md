# Единый поиск и команды

## Как пользоваться

1. Нажмите **Поиск** в верхней панели или **Ctrl+K**.
2. Введите часть ID, названия, владельца или текст документа.
3. Выберите результат мышью или клавишами **↑/↓**, затем **Enter**. **Esc** закрывает поиск.

Поиск объединяет все доступные разделы активного проекта и текст поддерживаемых артефактов. Команды позволяют открыть редактор, проекты, мастер создания, конструктор схем и другие разделы.

## Пример

В ShopFlow введите `Logistics`: среди результатов появится Delivery Service. Нажмите Enter, чтобы открыть его паспорт. Введите `OrderConfirmed`, чтобы найти исходные документы со сценарием оформления заказа.

## Ограничения

Поиск работает в выбранном проекте, а не во всех подключениях одновременно. Выдача ограничена; уточняйте запрос для больших наборов. Поиск исходного текста требует локального API и имеет ограничения размера/числа файлов. Без связи доступен поиск объектов ранее загруженной модели. Для открытия документа в портале должен быть настроен его адрес; исходный текст показывается безопасно, без выполнения HTML.
