# SEAF 2.3.0 — интерактивная рабочая область схем

Поставка **2.3.0** собрана из отдельного проверенного source Git и прошла проверку окончательного ZIP, включённых модулей и переноса в другую папку Windows. Она заменяет 2.2.0. Версия ядра остаётся **2026.33.0**. Работающий экземпляр обновлён, ShopFlow и Hello перезагружены без проблем; функциональные исходники опубликованы в закрытом GitHub и проверены по commit, дереву и приватности.

## Поведение

Полотно становится основной рабочей областью: палитра, выбор узлов/линий, панель свойств, масштаб, перемещение вида и вписывание. Из инспектора пользователь меняет свойства реальных объектов, состав DocHub-компонентов, интеграции и потоки данных. Справочники и enum опираются на метамодель проекта; дополнительные свойства сохраняются.

Оформление и правки модели различаются явно. Геометрия не меняет родителя, а семантические операции объединяются со схемой в один черновик: diff → проверка → один Git-коммит/локальная ревизия → обновление SEAF. Изменившийся источник, read-only и неустранённые ссылки блокируют сохранение. Незавершённый ввод, отмена и восстановление не создают коммитов.

## Инструкции и ограничения

Меню **Доработки LSV → 22. Интерактивный редактор схем** содержит управление полотном, свойства, состав, интеграции/потоки, пример Orders/API/Delivery и запись файлов.

Канонические инструкции сохранены через MCP в основном ShopFlow и двух примерах. Основной ShopFlow и Hello подтвердили reload `updated`, проблем — 0. В Hello проверено отображение нового руководства; активным снова выбран ShopFlow.

Рабочий экземпляр запущен из проверенного комплекта 2.3.0. Все три локальных сервиса здоровы; сохранены **9 подключений** (6 read-only), **15 локальных ревизий и 5 снимков** с проверкой целостности истории. Прежняя установка и данные сохранены. Ярлык использует обновлённый launcher; архитектурные файлы при миграции и восстановлении порталов не менялись. В пользовательском браузере проверены полотно и реальные поля инспектора без сохранения тестовых правок.

Состав DocHub основан на dotted ID. Перенос существующих поддеревьев не входит в это изменение. Пользовательские иерархии и конечные точки требуют поддерживаемого объявленного отображения. Известные ссылки модели проверяются; произвольный Markdown не переписывается автоматически. Совпадающие линии доступны через список связей; автоматическая трассировка в обход узлов не заявляется. Для новых модельных привязок схем требуется редактор 2.3 или новее.

## Публикация

Единственное назначение исходников — **private `flaojke/seaf-portable-workbench` на GitHub**. Другие проекты, GitVerse, рабочие подключения, история пользователя и подробные локальные отчёты не публикуются. Исходный workspace Git не отправляется: для выпуска создаётся новая проверенная история.

Изменения [UX 1–10](../openspec/changes/archive/2026-11-10-improve-seaf-usability/tasks.md) и [интерактивного редактора](../openspec/changes/archive/2026-11-10-enhance-diagram-workspace/tasks.md) архивированы pinned CLI с `--skip-specs --yes`; все 19 master-файлов сохранены без изменений. После архива OpenSpec strict: **20/20 PASS**. Прежнее незавершённое `add-stack-diagram-views` в этот выпуск не включено как принятое изменение.

Сводки испытаний сохраняют реальные статусы и агрегаты; полные исходные отчёты остаются локально. Три скриншота старой документации, отклонённые автоматической проверкой публикации, исключены из source export; вместо изображения в README оставлена обычная ссылка на оригинал SEAF. Это не меняет runtime-файлы ранее проверенной поставки 2.2.
